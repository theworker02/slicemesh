# slicemesh

Slice timestamps and mesh durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/slicemesh/

## Install / run

```bash
git clone https://github.com/theworker02/slicemesh.git
cd slicemesh
node src/cli.js
node --test
```
